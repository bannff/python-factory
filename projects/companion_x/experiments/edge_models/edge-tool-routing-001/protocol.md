# Protocol: edge-tool-routing-001

**Question:** Can a small local semantic model map an operator request to a
permitted, typed **read-only** capability or abstain when the request is
ambiguous or outside scope?

Begin with a small Ditto-like request set covering four to six safe
capabilities, argument extraction, ambiguous requests, and out-of-scope cases.
Record who authored and reviewed examples. If examples are generated by an
agent, label this as a synthetic task probe and split by paraphrase/template
family; its score must not be presented as real-operator performance. A later
human-labeled cohort is required for promotion.

Compare a keyword/rule router with an [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)
embedding-based router and a small deterministic decision head. The model is
22.7M parameters under Apache-2.0 according to its model card. Record the
exact model revision and weight hash. Report exact tool choice **and**
arguments, unsafe misroutes, out-of-scope abstention, latency, artifact bytes,
and cohort-level counts. No request may directly execute a physical action.

Record the typed request fields and publish frozen JSONL partitions with the
Dataset brick after external validation. FunctionGemma 270M is a distinct generative
tool-calling candidate; its official weights require acceptance of Google's
Gemma terms, and it must be evaluated separately on the same frozen tool
schema and holdout once access and a real inference path are available.

Later gates are converted-model parity and iPhone resource measurements,
local Ditto SDK persistence, and correct request/result sync over disconnected
peers with duplicate and stale-request checks.

## Reproduce the lab run

Download the pinned `sentence-transformers/all-MiniLM-L6-v2` revision from
the model card into `model/` next to [the frozen runner](run.py), then verify
the weight hash and revision in the [run index](run-index.json). With
PyTorch, Transformers, and NumPy installed, run `python run.py`. It emits the
synthetic dataset, predictions, and `results.json`; those generated files and
model weights remain ignored by Git. The post-hoc safety gate in this runner
must be evaluated on a new corpus before any confirmatory claim.
